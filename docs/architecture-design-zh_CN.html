FlowVerse VS Code 扩展架构

用于预览 Workspace 中单个 FlowVerse Light 服务架构 JSON 的自定义编辑器 Webview。

Extension Host

  • • 为服务架构 JSON 注册自定义编辑器
  • • 通过 VS Code Workspace API 读取文件
  • • 从 Manifest 或常用路径发现 Worldview
  • • 仅向 Webview 发送经过清理的文本载荷

Webview 运行时

  • • 在 VS Code Webview 中运行 React + Vite UI
  • • 使用 FlowVerse 预览图和验证代码
  • • 使用相同的架构画布技术进行渲染
  • • 在 MVP 中保持图表只读

FlowVerse 契约

  • • 服务架构 JSON 是事实来源
  • • Worldview JSON 提供词汇和视觉上下文
  • • 开放端点呈现为预览终端节点
  • • 数据流覆盖支持高亮和评审

FlowVerse 扩展设计 • VS Code 自定义编辑器 + React Flow Webview • 为架构评审生成

Native Copilot agent contract

  • • The participant owns request routing, streaming, references, command buttons, and registered follow-ups through the Chat Participant API.
  • • The model selected by the user performs reasoning and tool choice; FlowVerse does not contribute a custom model provider.
  • • The bounded loop allows up to eight model rounds and sixteen tool calls with cancellation and token budgets propagated.

Evidence before recommendation

  • • The Language Model Tool API exposes typed tools; extension-host services validate every result.
  • • Jira, architecture, repository/test evidence, and exact source revisions feed a single session and versioned artifact contract.
  • • Missing or partial evidence stays visible as findings and unknown readiness gates rather than being filled with guesses.

Explicit mutation boundary

  • • Webviews display and select; they cannot run AI, approve plans, or mutate Jira.
  • • Planning is a dry run. Apply requires the exact one-use plan ID and digest plus native confirmation.
  • • Knowledge and Jira revisions are rechecked before execution; partial outcomes are visible and retryable changes require a fresh plan.

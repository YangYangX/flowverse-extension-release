原生 Copilot Agent 契约

  • • 参与者通过 Chat Participant API 管理请求路由、流式输出、引用、命令按钮和已注册的后续操作。
  • • 用户选择的模型负责推理和工具选择；FlowVerse 不提供自定义模型服务。
  • • 有边界的循环最多允许八轮模型交互和十六次 Tool Call，并传播取消信号和 Token Budget。

先有证据，再给建议

  • • Language Model Tool API 公开类型化工具；Extension Host 服务验证每个结果。
  • • Jira、架构、仓库/测试证据和精确来源修订版本共同进入一个会话和版本化 Artifact 契约。
  • • 缺失或不完整证据会继续显示为发现和 Unknown 就绪度门禁，而不会用猜测补全。

显式变更边界

  • • Webview 负责显示和选择；不能运行 AI、批准计划或修改 Jira。
  • • 规划为 Dry Run。Apply 需要精确的单次 Plan ID、Digest 和原生确认。
  • • 执行前会重新检查知识和 Jira 修订版本；部分结果保持可见，需要重试的变更必须创建新计划。

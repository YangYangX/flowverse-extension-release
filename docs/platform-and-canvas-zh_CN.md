# 平台模型与画布

[English](platform-and-canvas.md)

本指南介绍 FlowVerse 如何组合由来源支撑的产品知识，并通过共享画布和详细信息工作台呈现这些知识。

## 产品模型

FlowVerse 遵循一条统一的组合链：

```text
共享数据契约
  -> 领域 worldview.instance.json
    -> 领域记录（*.architecture.json、*.jira.json 等）
      -> 画布投影
```

`unified-worldview.instance.json` 在不复制记录的前提下组合这些独立管理的领域。它声明：

- 共享数据契约；
- 各领域的 Worldview；
- 跨领域关系类型；
- 引用 `*.links.json` 断言的 Link Set。

每个画布都是同一组已加载源数据的投影。打开领域画布、统一画布、资源管理器或详细信息面板都不会创建另一份权威副本。

JSON 契约保持语义化且与渲染器无关。它们定义概念、记录、类型、关系、视图和布局意图。卡片设计、颜色、图标、边渲染、选择行为、工具栏和 Minimap 样式属于本扩展，作为默认渲染应用的一部分。

## 当前画布

### Unified Worldview

Unified Worldview 画布在一个通用画布上组合所有已启用领域及其跨领域链接。因此，一个交付工作项可以连接到其覆盖、实现或依赖的服务、模块、交互或其他可寻址架构元素。

### System Architecture

System Architecture 画布呈现系统、引用系统、模块、交互、基础设施和有序数据流。视觉映射由架构数据中保存的工作项类型驱动，因此同一类型在整个画布中使用一致的渲染器颜色和卡片样式。

### Agile Delivery

Agile Delivery 画布呈现来自 `*.jira.json` 记录的 Jira 风格工作项。其默认组织结构图布局来自领域 Worldview 的语义视图配置：父项占据一个层级，兄弟项共享下一层级。`blocks`、`depends on`、`implements`、`relates to` 和 `has defect` 等非结构关系仍以语义边显示。

其详细信息视图将运行上下文与关系、交付证据、讨论历史、AI 评分和来源沿袭分开。Agile Delivery Worldview 管理可用的评估配置，包括因素名称、描述、权重、聚合方式和评分区间；扩展负责执行并呈现所选配置。除非源数据显式包含评估，否则生成的评分仅保留在当前会话中。

## 共享画布行为

所有领域视图和统一视图都使用 `src/flowverse/workbench/` 中的同一画布引擎，以及 `src/webview/features/domainCanvas/` 中的同一画布界面。

- 单击高亮卡片或边；双击同时高亮并聚焦。
- 选择一条边会高亮两个端点，并淡化无关卡片和边。
- 从资源管理器选择元素时，会在需要时打开相应画布，然后应用同一套高亮与聚焦策略。
- 选择数据流会高亮完整路径；选择步骤会把高亮范围缩小到该步骤。
- Bundle 模式与边选择和数据流选择兼容。
- 可选的边数据流 Popover 默认关闭。
- 缩放 `100%` 表示 React Flow 实际尺寸。适应视图、缩放预设、实际尺寸、Minimap、路由、Bundle 和重置使用共享控件。
- Minimap 默认隐藏，并使用当前领域的渲染器主题。
- FlowVerse Legend 会随当前画布切换，并使用与画布相同的节点和边映射。

FlowVerse Explorer 使用延迟树加载。展开领域只会加载其树子项；单击领域会打开其画布和详细信息。关闭编辑器不会清除资源管理器数据。

## 详细信息工作台

共享详细信息工作台提供 **Overview**、**Data Flows**、**Source** 和 **Review** 标签页。领域模块可以提供领域专属区块，但不会替换工作台外壳。

- Overview 的值来自所选源记录，或基于已加载模型计算的汇总数量。
- 选择数据流时显示有序步骤；选择系统、模块和引用时，显示所有相关数据流的可排序登记表。
- Source 呈现来源和沿袭。
- Review 呈现由证据支撑的治理、风险和验证信息。
- 企业级表格支持排序和拖动调整列宽，同时保持表格总宽度不变。

对于 Agile Delivery，同一外壳提供 **Overview**、**Relationships**、**Evidence**、**Comments**、**AI Rating** 和 **Source**。Overview 包含运行标识和规划上下文；Evidence 管理需求、验收与完成条件、风险和待决事项；Comments 保留由来源支撑的作者和时间戳。AI Rating 展示综合评分、带颜色区间的因素评分、依据和优先建议，同时不修改源工作项。

除标签、色调和格式等必要的通用呈现映射外，详细信息应用不会制造业务信息。

## 来源与断言优先级

对于同一来源，Workspace 或显式加载的项目数据优先于内置默认数据。内置资源是安全回退，而不是竞争性的运行时数据集。

等价的跨领域关系使用以下权威顺序：

1. 会话中经用户确认的断言；
2. Workspace 中显式的 Link Set 断言；
3. 运行时推断关系。

类型、方向或端点对不同的关系会保留为独立断言。

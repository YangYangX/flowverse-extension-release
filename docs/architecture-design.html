FlowVerse VS Code Plugin Architecture

Custom editor webview for previewing one FlowVerse Light service architecture JSON from the workspace.

Extension Host

  • • Registers a custom editor for service architecture JSON
  • • Reads files through VS Code workspace APIs
  • • Detects worldview from manifest or common paths
  • • Sends only sanitized text payloads into the webview

Webview Runtime

  • • React + Vite UI running inside VS Code webview
  • • Uses FlowVerse preview graph and validation code
  • • Renders the same architecture canvas technology
  • • Keeps the diagram read-only in the MVP

FlowVerse Contract

  • • Service architecture JSON is the source of truth
  • • Worldview JSON supplies vocabulary and visual context
  • • Open endpoints render as preview terminal nodes
  • • Data-flow coverage powers highlighting and review
